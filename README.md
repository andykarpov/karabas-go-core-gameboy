# Game Boy / Game Boy Color core for Karabas Go, Mini and Mini G

A port of the MiSTer Gameboy core (via [open-pocket-gbc](https://github.com/LakoMoor/open-pocket-gbc)) to the Karabas boards (Xilinx Spartan-6 XC6SLX25). Work in progress: see [docs/PLAN.md](docs/PLAN.md) (in Russian).
